# Sudoku Solver

A simple, interactive Sudoku Solver built with **HTML, CSS, and JavaScript**. Enter your own Sudoku puzzle or load an example, then solve it automatically using a backtracking algorithm.

## Features

- Interactive 9×9 Grid— Enter numbers from 1 to 9.
- Automatic Solver — Solve Sudoku puzzles using backtracking.
- Puzzle Validation — Check for conflicting numbers.
- Example Puzzle — Load a sample Sudoku instantly.
- Clear Board — Reset the grid and start again.
- Dark Theme — A modern, dark-themed interface.
- Responsive Design— Works on desktop and mobile screens.

## Technologies Used

- HTML — Website structure.
- CSS — Styling, layout, and responsive design.
- JavaScript — Sudoku logic, validation, and solving algorithm.
